## 📖 definition

**ephraimphrase** *(n.)*

1. A builder who speaks in code the way other people speak in sentences.
2. One who turns a vague idea into a working system, usually before the coffee gets cold.
3. *(verb)* To phrase a problem so well that the solution shows up on its own.

> **Etymology:** *Ephraim*, from the Hebrew אֶפְרַיִם, "doubly fruitful" + *phrase*, from the Greek *phrasis*, "a way of speaking."
> Literally: **one who speaks fruitfully, twice.**
> Evidence in support: 49 repositories. The name checks out.

## 💬 used in a sentence

My projects are best explained by the moment you'd need them.

> *"Is it going to rain in Lagos?"*
> → **[SurgeWeatherly](https://github.com/ephraimphrase/Surgeweatherly)**: weather and a map for any city you search. Built for the web in Python, then rebuilt in **[Flutter](https://github.com/ephraimphrase/SurgeWeatherly-flutter)** so it fits in a pocket.

> *"Just send me the file."*
> → **[SurgeFiles](https://github.com/ephraimphrase/SurgeFiles)**: file sharing without the ceremony.

> *"Not here. Somewhere private."*
> → **[privy](https://github.com/ephraimphrase/privy)**: a chat app built on Django and jQuery.

> *"Did the client pay? When's the milestone due?"*
> → **[workfront-mobile](https://github.com/ephraimphrase/workfront-mobile)**: a Flutter app that tracks freelancers' gigs, milestones, deadlines and payments.

Notice the pattern: the **Surge** family answers small daily questions, and `workfront` answers the one every freelancer asks at the end of the month.
